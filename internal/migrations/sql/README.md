# goose migrations

- `00001_baseline.sql` is generated by `LuminaVaultServer/scripts/schema-snapshot.sh`
  (Phase 0 Task 0.5). It holds the schema Swift's Fluent migrations produce,
  plus the rows those migrations seed. Never edit it by hand.
- Every Swift migration added after the baseline needs a mirrored goose file
  here, with the header `-- mirrors: <SwiftMigrationName>`, in the same change.
  `scripts/check-migration-mirror.sh` enforces this in CI.
